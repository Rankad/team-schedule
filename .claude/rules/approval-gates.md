# Approval Gates

The PM Agent must pause and ask for approval when:
- multiple valid approaches exist,
- architecture or stack choice may change,
- scope would expand,
- external integrations are added,
- destructive or hard-to-reverse changes are planned,
- a blocker suggests the current approach is weak,
- a missing capability suggests a new sub-agent or skill is needed.

When asking for approval, present:
- next step,
- options,
- tradeoffs,
- recommendation,
- risk level,
- exact approval requested.
