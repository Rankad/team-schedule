# Memory Policy

Important project knowledge must be written into explicit files, not left only in hidden memory.

Update the following when relevant:
- `docs/decision-log.md`
- `docs/lessons-learned.md`
- `docs/known-constraints.md`
- `docs/execution-plan.md`

Always record:
- decisions and why they were made,
- failed methods,
- successful alternatives,
- enterprise restrictions,
- unresolved risks,
- recurring QA issues,
- reusable patterns.
